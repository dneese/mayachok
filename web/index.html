Маячок

Сімейний GPS-трекер у режимі реального часу. Усі бачать один одного на карті.

Завантажити APK (Android) Про проєкт на GitHub

Введіть код групи або створіть нову групу.

Код зберігається в адресному рядку (#)... Він нікуди не надсилається окремо — тільки разом із запитом.

Як це працює
  1. Відкрийте посилання групи або створіть свою.
  2. Надішліть посилання родичі чи друзям.
  3. Кожен ставить APK, вводить ім’я й код, натискає «Почати».
  4. Усі з’являються на карті; імена змінюються на цій сторінці.
