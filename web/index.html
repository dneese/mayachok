Код для ручного введення
—

Код живе у частині адреси після #. Сайт GitHub його не отримує, а на сервері зберігається лише короткий хеш. Повний код потрібен, щоб знайти групу, тому не пересилайте посилання стороннім.

Як це працює

  1. Кожен встановлює застосунок і вводить код групи.
  2. Натискає «Почати» — дозволяє геолокацію.
  3. Трекер працює у фоні й надсилає точку кожні 30 секунд.
  4. Усі групу бачать один одного на цій мапі.

Як додати людину

  1. Надішліть їй посилання на цю групу.
  2. Вона відкриває посилання на проєкт і ставить застосунок звідти.
  3. Вводить ім’я та код, натискає «Почати».

Коли не видно людей
