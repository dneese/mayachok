# Маячок

**Сімейний і туристичний GPS-трекер.** Група людей ставить застосунок, усі бачать
один одного на карті в реальному часі. Приватність — за кодом групи.

## Швидкий старт

1. Відкрийте [мапу](https://dneese.github.io/mayachok/) і натисніть **«Створити групу»**.
2. Скопіюйте посилання — воно вже містить код групи.
3. Надішліть посилання родичі чи друзям.
4. Вони встановлюють [APK](https://github.com/dneese/mayachok/releases/latest), вводять
   ім’я, вставляють код і натискають **«Почати»**.
5. Усі з’являються на карті один в одного.

Код виглядає так: `b4rd-kg4c-q5ye` — 12 символів, групи по чотири. Літери `i l o u`
заховані, щоб не плутати при диктуванні телефоном. Дефіси необов’язкові,
регістр не важливий: `b4rdkg4cq5ye` — те саме.

### Як показувати людей

- Опитування кожні 10 секунд.
- Маркер = остання точка. Колір: зелений < 2 хв, жовтий < 30 хв.
- Після 30 хв без оновлення маркер **приховано** — видно «хто де зараз», а не «де був».
- Клік по людині малює слід за 1, 3 або 12 годин.
- ⌖ підганяє межі мапи під усіх.

## Складники

| Частина | Технології | Де |
|---|---|---|
| Android-застосунок | Java, чистий SDK, **без залежностей** | [`app/`](app) |
| API та сховище | Cloudflare Worker + D1 | [`worker/`](worker) |
| Мапа | Leaflet + OpenStreetMap, статика | [`web/`](web) |

APK виходить ~32 КБ: жодних AndroidX, Google Play Services чи сторонніх бібліотек.
Збірка — `aapt2` → `javac` → `d8` → `apksigner`, без Gradle.

```
APK  ──▶  Cloudflare Worker  ──▶  D1
                                    │
             мапа (GitHub Pages) ───┘
```

## Приватність

- Код групи живе у **фрагменті** адреси (після `#`), тож браузер не надсилає його
  на сервер ні з GitHub, ні з Cloudflare — і він не потрапляє в логи чи реферер.
- На сервер іде лише `gid = SHA-256(code)[0..15]`. **Сам код у базі не зберігається**
  у жодній таблиці, тож дамп D1 не розкриває доступи.
- Кожен бачить тільки свою групу: фільтр `gid` виконується на сервері, браузер
  ніколи не отримує чужих груп.
- Точки старші за 48 годин видаляються щодоби, учасники без активності понад
  30 днів — теж.

## API

Усі запити вимагають `code`. `hours` обмежено 12.

| Роут | Призначення |
|---|---|
| `POST /api/create` | створює групу, повертає код |
| `GET /api/ingest?uid=&code=&lat=&lon=&t=&acc=&bat=&name=` | прийом точки |
| `GET /api/group?code=` | активні учасники групи |
| `GET /api/track?code=&uid=&hours=` | історія як GeoJSON |
| `POST /api/rename` | `{code, uid, name}` — перейменування |
| `GET /api/health` | стан |

Сумісність: `?lat=&lon=&t=` без `/api/` теж приймається — старий скрипт
`gps.php` працює як задумано.

## iPhone

**Рідного застосунку для iOS поки немає.** Причина практична: iOS не дозволяє
стороннім застосункам постійно відстежувати геолокацію у фоні — тобто працювати
як Маячок, доки телефон заблокований. Це обмеження самої системи, а не збірки.

Робочі варіанти, які уже влаштовуються:

- **PWA в браузері.** Відкрийте мапу в Safari → «Поділитися» → **«На екранний
  стіл»** (Add to Home Screen). Працюватиме як встановлена іконка, але координати
  надсилатиме лише поки вкладка відкрита. Точність нижча за системну, зате без
  жодного root.
- **Shortcuts + Automator.** Невеликий скрипт на Python із Termux або Mac надсилає
  координати за розкладом — те саме, що робить застосунок Android.

Якщо потрібен повноцінний фоновий трекінг на iOS — це вже потребує підписаної
розширеної апки в App Store, плюс стійке дозволо на Always-on location. Напишіть,
якщо варто йти цим шляхом.

## Розгортання

Ключі читаються з локального бекапу (файл поза репозиторієм):

```bash
source scripts/secrets.sh     # експортує CF_API_TOKEN і CF_ACCOUNT_ID

bash scripts/setup-d1.sh      # створює D1 + накатує schema.sql
bash scripts/deploy-worker.sh # завантажує Worker через REST API
```

`wrangler` на Termux не працює, тому скрипти ходять у Cloudflare REST API напряму.

## Збірка APK

```bash
cd app
bash build.sh
```

Потрібні `aapt2`, `d8`, `apksigner` і `android.jar`. На Termux:

```bash
pkg install aapt2 d8 apksigner aapt
mkdir -p ~/.cache/gps-tracker && cd ~/.cache/gps-tracker
curl -LO https://dl.google.com/android/repository/platform-35_r02.zip
unzip -o platform-35_r02.zip 'android-35/android.jar'
mv android-35/android.jar .
```

Релізи збирає GitHub Actions при пуші тега `v*` — див.
[`.github/workflows/apk.yml`](.github/workflows/apk.yml). Сторінку публікує
[`pages.yml`](.github/workflows/pages.yml).

> Підпис — тимчасовий ключ, який генерується при першій збірці. Для стабільних
> оновлень варто завести власний `keystore` і передати його в CI як secret.

## Обмеження

- GPS має бути увімкнений у системі; застосунок сам його не вмикає.
- Фонова робота тримається на foreground service — нотифікацію не можна прибрати,
  інакше Android зупинить сервіс.
- Витрата батареї: інтервал 30 с ≈ 3%/год. Частіше — точніше, але дорожче.
