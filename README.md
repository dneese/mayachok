# Маячок

Сімейний і туристичний GPS-трекер. Група людей ставить застосунок, усі бачать
один одного на карті. Приватність — за кодом групи.

```
APK  ──▶  Cloudflare Worker  ──▶  D1
                                    │
             мапа (GitHub Pages) ───┘
```

## Складники

| Частина | Технології | Де |
|---|---|---|
| Android-застосунок | Java, чистий SDK, **без залежностей** | `app/` |
| API та сховище | Cloudflare Worker + D1 | `worker/` |
| Мапа | Leaflet + OpenStreetMap, статика | `web/` |

APK виходить ~32 КБ: жодних AndroidX, Google Play Services чи бібліотек.

## Як користуватись

1. Відкрийте `https://dneese.github.io/mayachok/` і натисніть **«Створити групу»**.
2. Скопіюйте посилання — воно містить код групи.
3. Надішліть посилання родичі чи друзям.
4. Кожен встановлює APK, вводить ім'я, вставляє код, натискає **«Почати»**.
5. Усі з'являються на карті один в одного. Імена можна змінити на самій сторінці.

Код групи живе у фрагменті адреси (після `#`), тож сервер його не отримує.
На сервер потрапляє лише `gid = SHA-256(code)[0..15]` — сам код не зберігається.

Вигляд коду: `b4rd-kg4c-q5ye` — 12 символів, групи по чотири, літери `i l o u`
заховані, щоб не плутати при диктуванні телефоном. Дефіси необов'язкові —
`b4rdkg4cq5ye` те саме.

## Як працює показ

- Опитування `/api/group` кожні 10 секунд.
- Маркер = остання точка. Колір кодує свіжість: зелений < 2 хв, жовтий < 30 хв.
- Після 30 хв без оновлення маркер **приховано** — «хто де зараз», а не «де був».
- Клік по людині малює слід за вибраний інтервал: 1, 3 або 12 годин.
- ⌖ підганяє межі мапи під усіх.

## API

| Роут | Призначення |
|---|---|
| `POST /api/create` | створює групу, повертає код |
| `GET /api/ingest?uid=&code=&lat=&lon=&t=&acc=&bat=&name=` | прийом точки |
| `GET /api/group?code=` | активні учасники групи |
| `GET /api/track?code=&uid=&hours=` | історія як GeoJSON |
| `POST /api/rename` | `{code, uid, name}` — перейменування |
| `GET /api/health` | стан |

Усі запити вимагають `code`. `hours` обмежено 12.

Сумісність: `?lat=&lon=&t=` без `/api/` теж приймається — старий скрипт
`gps.php` працює як задумано.

## Розгортання

Ключі читаються з локального бекапу (файл поза репозиторієм):

```bash
source scripts/secrets.sh     # експортує CF_API_TOKEN і CF_ACCOUNT_ID

bash scripts/setup-d1.sh      # створює D1 + накатує schema.sql
bash scripts/deploy-worker.sh # завантажує Worker через REST API
```

`wrangler` на Termux не працює, тому скрипти ходять у Cloudflare REST API напряму.

## Збірка APK

```bash
cd app
bash build.sh
```

Потрібні `aapt2`, `d8`, `apksigner` і `android.jar`.

На Termux:

```bash
pkg install aapt2 d8 apksigner aapt
mkdir -p ~/.cache/gps-tracker && cd ~/.cache/gps-tracker
curl -LO https://dl.google.com/android/repository/platform-35_r02.zip
unzip -o platform-35_r02.zip 'android-35/android.jar'
mv android-35/android.jar .
```

Публічні релізи збирає GitHub Actions при кожному пуші в `app/` — див.
`.github/workflows/apk.yml`.

> Підпис — тимчасовий ключ, який генерується при першій збірці. Для стабільних
> оновлень власний `keystore` і передача його в CI як secret.

## Обмеження

- GPS має бути увімкнений у системі; застосунок сам його не вмикає.
- Фонова робота тримається на foreground service — нотифікацію не можна
  прибрати, інакше Android зупинить сервіс.
- Старі точки (>48 год) видаляються щодоби.
